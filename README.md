# ORIS DENTAL — концепт сайта стоматологической клиники

Демонстрационный проект для портфолио веб-студии. Все данные на сайте (название, контакты, адрес, описания) — **концептуальные** и явно помечены на страницах.

## Запуск

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # сборка в /dist
npm run preview  # просмотр собранной версии
```

## Структура

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка всех 11 секций |
| `src/styles.css` | Визуальная система: цвета, типографика, адаптив |
| `src/data.js` | Направления, услуги, FAQ, время записи — меняется без правки разметки |
| `src/main.js` | Меню, scrollspy, фильтр услуг, панель подробностей, FAQ, форма записи |
| `src/tooth-viewer.js` | 3D-модель зуба (Three.js): загрузка GLB, заглушка, точки-подсказки |
| `src/tooth-sdf.js` | Процедурная модель-заглушка: гладкая поверхность по полю расстояний (SDF), строится в Web Worker |

## 3D-модель зуба

Положите файл модели сюда:

```
public/models/dental-tooth.glb
```

- Если файл есть — сайт загрузит его автоматически.
- Если файла нет — показывается процедурная модель моляра (заглушка).
- Модель автоматически центрируется и масштабируется. Ось «вверх» — Y (стандарт glTF).
- Информационные точки задаются в `HOTSPOTS` (`src/tooth-viewer.js`) в относительных координатах: высота `h` от 0 (низ) до 1 (верх) и угол `angle` вокруг оси. Точки «прилипают» к поверхности любой модели, поэтому после замены GLB их обычно не нужно пересчитывать.
- Режим «Внутри» показывает модель в просвет. У процедурной заглушки видна пульпа; для своей GLB можно добавить внутренний объект с именем `pulp` — он будет показан только в этом режиме.

## Перед адаптацией под реальную клинику

- Используйте только проверенную информацию, предоставленную клиникой: лицензии, квалификацию и имена врачей, цены, адрес.
- Не публикуйте вымышленные отзывы, сертификаты и гарантии результата лечения.
- Фото врачей и пациентов — только реальные и с согласия.
- Форма записи сейчас демонстрационная и никуда не отправляет данные. Подключите её к CRM или почте клиники и добавьте ссылку на политику обработки персональных данных.
- Карта в «Контактах» — схема-заглушка, замените её на виджет карты с реальным адресом.
